# 🎓 المساعد التربوي والتعليمي الذكي للمعلمين والمدارس

منصة وتطبيق متكامل لدعم المعلمين والتربويين في إعداد المحتوى التعليمي، وتصميم خطط الدروس النموذجية، وصياغة الاختبارات التحصيلية، وأوراق العمل التفاعلية، وتبسيط المفاهيم الصعبة باستخدام الذكاء الاصطناعي التوليدي عبر **Google Gemini API** (`@google/genai`).

---

## 🌟 الميزات والمخرجات التعليمية

- **📚 خطط دروس نموذجية متكاملة**: تتضمن الأهداف السلوكية (تصنيف بلوم)، التهيئة الحافزة، سير الأنشطة، استراتيجيات التدريس، وأدوات التقويم وغلق الدرس.
- **📝 بنك أسئلة واختبارات تقويمية**: صياغة أسئلة موضوعية ومقالية مع نموذج الإجابة وسلم تقدير الدرجات (Rubrics).
- **📐 أوراق عمل تفاعلية**: تدريبات صفية متدرجة الصعوبة تراعي الفروق الفردية بين الطلاب.
- **💡 تبسيط المفاهيم**: شروحات تعليمية تشبيهية ممتعة وسهلة الفهم مبنية على أمثلة من الواقع المعاش.
- **👥 أنشطة التعلم النشط**: مهام أدائية تعاونية، استراتيجية فكر-زاوج-شارك، العصف الذهني، وحل المشكلات.
- **🎙️ إذاعة مدرسية متكاملة**: برامج إذاعية تشمل المقدمة، الآيات، الأحاديث، كلمة الصباح، وحكمة اليوم.
- **💌 تواصل مع أولياء الأمور**: صياغة رسائل تربوية إيجابية لتعزيز الدافعية والانضباط.
- **📄 تصدير فوري إلى PDF عالي الجودة**: إمكانية تنزيل أي مخرج تعليمي كملف PDF جاهز للطباعة والتوزيع على الطلاب.
- **🐍 دعم تطبيق Streamlit و Python**: توفير ملفات `streamlit_app.py` و `requirements.txt` لنشر التطبيق بسهولة على Streamlit Community Cloud.

---

## 🛠️ متطلبات التشغيل

- **Node.js** (الإصدار 18 أو أحدث)
- مفتاح **Gemini API Key** من [Google AI Studio](https://aistudio.google.com/)

---

## 🚀 التشغيل المحلي (React + Express)

1. **استنساخ المستودع (Clone)**:
   ```bash
   git clone <URL-المستودع>
   cd <اسم-المجلد>
   ```

2. **تثبيت الحزم (Dependencies)**:
   ```bash
   npm install
   ```

3. **إعداد المتغيرات البيئية**:
   قم بإنشاء ملف `.env` مستنداً إلى `.env.example`:
   ```env
   GEMINI_API_KEY=ضع_مفتاحك_هنا
   ```

4. **تشغيل بيئة التطوير**:
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

5. **بناء الإنتاج (Production Build)**:
   ```bash
   npm run build
   npm start
   ```

---

## 🐍 تشغيل نسخة Streamlit (Python)

إذا أردت تشغيل نسخة Python/Streamlit المستقلة:

1. تثبيت المتطلبات:
   ```bash
   pip install -r requirements.txt
   ```
2. تعيين مفتاح API:
   ```bash
   export GEMINI_API_KEY="your_api_key_here"
   ```
3. تشغيل التطبيق:
   ```bash
   streamlit run streamlit_app.py
   ```
